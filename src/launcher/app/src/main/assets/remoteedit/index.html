Profiles

Atomic snapshots of layout + wallpaper + icon filter + transition. Switch by hand or set up triggers (WiFi, charger) and let the launcher swap automatically.

Widgets

Bundled and AI-generated widgets. Rename or edit the description of user-generated ones; delete any that aren't in use.

Wallpapers

Live previews of the bundled and AI-generated wallpapers. Click a card to switch.

Page transitions

Tap a tile to set it as the active page transition. User-generated transitions can be renamed, edited, or deleted.

Icon filters

A global visual treatment applied to every app icon. Tap to apply. User-generated filters can be renamed, edited, or deleted.

Clippings
